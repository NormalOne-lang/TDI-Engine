# موتور TDI: ابزار ETL و شبیه‌سازی تاکتیکی فوتبال

یک خط لوله مهندسی داده مبتنی بر پایتون که برای استخراج، پردازش و مصورسازی داده‌های تاکتیکی مسابقات فوتبال طراحی شده است.

**سلب مسئولیت:** این پروژه صرفاً به عنوان یک نمونه کار فنی جهت نمایش تکنیک‌های استخراج داده، تحلیل منطقی و معماری سیستم توسعه یافته است. این برنامه یک ابزار شبیه‌سازی تاکتیکی است و معیاری برای پیش‌بینی قطعی نتایج مسابقات یا ابزار شرط‌بندی محسوب نمی‌شود.

## نگاه کلی به پروژه

پلتفرم‌های مدرن داده‌های فوتبالی محدودیت‌های شدیدی روی دسترسی به APIهای خود اعمال می‌کنند. هدف این پروژه نمایش نحوه دور زدن برنامه‌نویسی‌شده این محدودیت‌ها با استفاده از تکنیک‌های پیشرفته استخراج، بدون نیاز به ابزارهای سنگین اتوماسیون مرورگر (مانند سلنیوم) است. این موتور داده‌های رندر شده در سمت سرور (SSR) را مستقیماً از تگ‌های JSON مخفی Next.js استخراج کرده، متریک‌های خام را جدا می‌کند و یک مدل ریاضی منطقی را برای شبیه‌سازی تقابل تاکتیکی دو تیم اعمال می‌نماید.

## ویژگی‌های فنی کلیدی

*   **استخراج شبکه بدون مرورگر:** استفاده از cloudscraper برای عبور از لایه‌های امنیتی وب و دریافت مستقیم پپ‌لودهای JSON بدون تحمیل بار پردازشی مرورگرهای کامل.
*   **پارس داینامیک داده‌ها:** تشخیص خودکار پس‌زمینه تیم میزبان و میهمان و استفاده از عبارات باقاعده (Regex) برای استخراج مقادیر عددی خالص از آرایه‌های متنی ترکیبی.
*   **الگوریتم تعدیل مالکیت توپ:** مدل شبیه‌سازی به جای تکیه بر میانگین‌های خام قبلی، خروجی‌های تاکتیکی (مانند xG و لمس توپ در محوطه) را بر اساس سهم مالکیت توپ تنظیم می‌کند. این امر مانع از افت غیرواقعی آماری تیم‌های ضدحمله‌ای در شبیه‌سازی می‌شود.
*   **مصورسازی خودکار داده‌ها:** رندر یک داشبورد گرافیکی ایستا با کیفیت بالا (PNG) با استفاده از matplotlib و scipy برای نمایش متقارن گشتاور مسابقه و شاخص‌های کلیدی.
*   **یکپارچگی با خط فرمان:** قابلیت اجرای کامل برنامه از طریق ابزار argparse خط فرمان، جهت آماده‌سازی اسکریپت برای خط لوله‌های CI/CD یا پردازش‌های دسته‌ای.

## پیش‌نیازها

    pip install -r requirements.txt

## نحوه استفاده

این اسکریپت از طریق خط فرمان اجرا می‌شود. شما باید آدرس بازی‌های گذشته دو تیم مورد نظر خود را به همراه نام دقیق آن‌ها به برنامه پاس دهید.

**نمونه دستور اجرا:**

    python TDI-Engine.py --match1 "https://www.fotmob.com/matches/team-1-url" --match2 "https://www.fotmob.com/matches/team-2-url" --team1 "France" --team2 "Spain"

پس از اجرای موفقیت‌آمیز، اسکریپت داده‌ها را پردازش کرده و فایل prediction_dashboard.png را در پوشه اصلی پروژه خروجی می‌دهد.

## نقاط برجسته معماری سیستم

*   برنامه‌نویسی شیءگرا (OOP) با تفکیک کامل وظایف بخش‌های استخراج، پارس داده، مدل ریاضی و داشبورد گرافیکی.
*   استفاده از سیستم لاگ استاندارد پایتون (Logging) به جای دستورات پرینت معمولی.
*   مدیریت خطا و استثناها در صورت تغییر ناگهانی ساختار JSON سایت یا قطع ارتباط شبکه.
